The Python port of scoreToHue:
```python
import math

def score_to_hue(score: float) -> float:
    """Port of TypeScript scoreToHue for testing."""
    if score < 0:
        if score >= -5:
            t = math.sqrt(-score / 5)
            return 90 + t * (264 - 90)
        else:
            t = math.sqrt((-score - 5) / 5)
            return 27 + t * (90 - 27)
    else:
        t = math.sqrt(score / 10)
        return 264 - t * (264 - 145)
```

Write tests covering: boundary values (-10, -5, -1, +1, +5, +10), monotonicity within each piecewise segment, and sqrt easing verification (comparing against linear interpolation to prove sqrt gives more separation at low scores).

Use `assertAlmostEqual` with `places=1` for hue comparisons (anchor values are approximate).
