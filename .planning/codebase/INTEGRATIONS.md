# External Integrations

**Analysis Date:** 2026-03-25

## APIs & External Services

**Linguistic Data Services:**
- CMU Pronouncing Dictionary (cmudict) - Used to look up phonemes for word encoding
  - SDK/Client: `cmudict` Python package >= 1.0.0
  - Type: Offline corpus (loaded at module init in `trainer/validator.py`)
  - Usage: Maps English words to IPA phonemes for Major System digit encoding

- NLTK WordNet - Used to filter concrete nouns for word association candidates
  - SDK/Client: `nltk` Python package >= 3.8
  - Type: Offline corpus with auto-download on first use
  - Usage: `trainer/generator.py` filters WordNet synsets to physical entities only
  - Auto-download: `ensure_nltk_data()` downloads `wordnet` and `omw-1.4` corpora if missing

**Internal REST API:**
- `/api/wordlist` (GET) - Returns 110-entry JSON mapping (0-9 single digits, 00-99 two digits)
- `/api/mapping` (GET) - Returns consonant-to-digit mapping reference
- `/api/state` (POST/GET) - Syncs client quiz state to server-side `QuizState` model
- `/api/candidates/<digits>` (GET) - Returns suggested concrete nouns for a given number
- `/api/encode` (POST) - Encodes arbitrary text words to Major System digits

## Data Storage

**Databases:**
- SQLite3 (default, production-ready)
  - Connection: `db.sqlite3` in project root (configured via `DJANGO_DATABASES['default']`)
  - Client: Django ORM (no external adapter needed)
  - Model: `trainer/models.py` → `QuizState` (single model for user/IP-based state persistence)

- Alternative: PostgreSQL supported (only requires changing `DATABASES` backend in `config/settings.py`)

**State Fields in QuizState Model:**
- User authentication: `user` (OneToOneField to Django User), `ip_address` (for anonymous tracking)
- Quiz modes: `quiz_scores`, `quiz_history`, `quiz_guesses` (Number→Word)
- Reverse mode: `reverse_scores`, `reverse_history`, `reverse_guesses` (Word→Number)
- Mixed mode: `mixed_scores`, `mixed_history`, `mixed_guesses` (Bidirectional)
- Consonant mode: `con_scores`, `con_history`, `con_guesses` (Sound mappings)
- Custom words: `custom_words` (User-defined word pool overrides)
- Analytics: `activity_log` (JSON dict of session timestamps)
- User preferences: `tutorial_seen`, `dyslexia_font`, `theme`, `updated_at`

**File Storage:**
- Local filesystem only
  - `wordlist.json` - Static cache of generated 110-entry word associations (committed to repo)
  - `static/js/app.js` - Built JavaScript bundle (not committed, generated by CI)
  - `static/css/app.css` - Built CSS file (not committed, generated by CI)
  - Cache busting: Django's `ManifestStaticFilesStorage` adds content hashes to filenames

**Caching:**
- Browser localStorage (client-side)
  - `quizState` - Full quiz state snapshot for offline support
  - `wordlist` - Cached 110-entry wordlist (checked before API fetch)
  - `mapping` - Cached consonant mapping (checked before API fetch)

- Process-level singletons (server-side)
  - `_wordlist` - Lazy-loaded once per process (never invalidated; static data)
  - `_candidate_map` - Lazy-loaded once per process (never invalidated; static data)

## Authentication & Identity

**Auth Provider:**
- Django's built-in authentication system (CustomUser not used)
  - Implementation: Standard Django User model with session-based auth
  - Session middleware: `django.contrib.sessions.middleware.SessionMiddleware`
  - CSRF protection: Enabled via `django.middleware.csrf.CsrfViewMiddleware`

**User Sessions:**
- Login endpoint: `POST /login/` (views.login_view)
- Register endpoint: `POST /register/` (views.register_view)
- Logout endpoint: `POST /logout/` (views.logout_view)
- CSRF token: Extracted from cookies via `getCookie('csrftoken')` in frontend (persistence.ts)

**Dual-Mode State:**
- Authenticated users: QuizState linked via `user` field
- Anonymous visitors: QuizState linked via `ip_address` (IP-based tracking)
- When user logs in: Server can migrate IP-based state to user account (not currently implemented)

## Static Content Serving

**Strategy:**
- Django ManifestStaticFilesStorage adds content-hash to filenames
- Static files versioned by CI: Run `python manage.py collectstatic` → files copied to `collected_static/` with `.abc123def456.js` style hashing
- Production web server (Nginx) configured to serve `collected_static/` with long-lived cache headers

## Word List Generation

**Data Pipeline:**
- `trainer/generator.py` → `load_or_generate_wordlist()` creates 110-entry JSON from NLTK WordNet
- Output: `wordlist.json` (10 single-digit nouns + 100 two-digit nouns)
- Criteria: Must be concrete (physical entity hyponyms), avoid slurs/abbreviations
- Fallback: Pre-generated `wordlist.json` committed to repo; regeneration only on explicit request
